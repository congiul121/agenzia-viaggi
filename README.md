# Agenzia viaggi

Landing page di un'agenzia di viaggi, realizzata come esercitazione del percorso Web Developer EPICODE.

## Cosa contiene
- Struttura della pagina in HTML5 semantico
- Layout responsive in CSS3 con Flexbox
- Sezioni: header di navigazione, presentazione delle mete, form di contatto

## Tecnologie
HTML5, CSS3

## Cosa ho imparato
Organizzare il markup in sezioni riutilizzabili e far reggere il layout dal desktop al mobile senza framework.
